# 사용 설명서 — 화면으로 만들기

애니메이터 · 연출자가 툴의 화면으로 **캐릭터 모션**과 **이모지**를 만드는 법이다.
**그림으로 따라 하는 판은 [`guide/README.md`](guide/README.md)다** — 처음이면 그쪽부터 본다. 이 문서는 조작 전부를 적은 글이다.
파일을 직접 써서 만드는 법(AI · 스크립트)은 [`AUTHORING-FILES.md`](AUTHORING-FILES.md)에 있다 — 두 길은 같은 파일을 만들고 서로 이어서 고칠 수 있다.

## 1. 시작

```
dotnet run --project src/Mt.App/Mt.App.csproj
```

(.NET 10 SDK가 있어야 한다.) 처음 열면 캐릭터 `s1`이 선 빈 문서가 뜬다. 리그는 **내장본**(유니티 덤프의 사본)이라 덤프 파일이나 초상 그림이 없어도 바로 만들 수 있다.

이 툴이 만드는 것은 셋이다.

| 만드는 것 | 어디서 | 내보내면 |
|---|---|---|
| **캐릭터 모션** — 초상을 끄덕이고 숙이고 뛰게 한다 | 캐릭터 모션 모드 | `motions.json` |
| **이모지** — 인물의 머리 곁에 뜨는 그림(느낌표 · 별 · 땀) | 이모지 모드 | `emojis.json` |
| **연출 클립** — 모션 여럿을 겹쳐 보고 구워서 모션 하나로 | 캐릭터 모션 모드의 타임라인 | (구운 모션이 `motions.json`으로) |

저장하는 파일은 **저작본**(`*.motion-authoring.json`) 하나다. `motions.json` · `emojis.json`은 거기서 내보낸 것이고 게임이 읽는다.

조작은 마야를 따른다. 단축키 전체는 툴 안의 **F1**과 [16절](#16-단축키).

## 2. 화면

툴바 맨 앞의 **캐릭터 모션 | 이모지**가 작업 모드다. 화면에는 그 일에 쓰는 것만 보인다. 가운데(뷰포트 · 슬라이더 · 그래프 · 도프 시트)는 두 모드가 같이 쓴다.

**캐릭터 모션 모드**

```
┌ 툴바: [캐릭터 모션 | 이모지] · 새로 · 열기… · 최근… · 저장 · 다른 이름으로… · 리그 덤프… · motions.json 가져오기… · 내보내기… · 되돌리기 · 다시하기 · 트윈머신 · 설정… · 단축키 (F1)
├───────────────┬──────────────────────────────────┬──────────────────┐
│ 씬 — 오브젝트  │ 뷰포트 (무대 · 초상 · 매니퓰레이터)  │ 탭 넷             │
│   하이어아키   │   도구 띠: 선택 Q · 이동 W · 회전 E │  채널 박스 (기본)  │
│ 모션 목록      │           · 크기 R · ● Auto Key   │  씬              │
│  모션 추가     │ 타임 슬라이더 · 재생 단추           │  모션            │
│  프리셋에서 추가│ 레인지 슬라이더                    │  클립            │
│ 클립 목록      ├──────────────────────────────────┤                  │
│               │ (클립을 고르면) 타임라인           │                  │
│               │ 그래프 / 도프 시트 탭              │                  │
├───────────────┴──────────────────────────────────┴──────────────────┤
│ 문제 칸 (막는 문제 ⚠ · 알림 △ · 고쳐 주는 단추)                           │
└─────────────────────────────────────────────────────────────────────┘
```

**이모지 모드**

```
├───────────────┬───────────────────────────────────────────┬─────────────────┐
│ 이모지 목록    │ 뷰포트 — 인물의 머리에 선 이모지             │ 고른 것의 값      │
│  이모지 추가   │   도구 띠: Q · W · E · R · ● Auto Key      │  이모지를 골랐으면 │
│  · 삭제 · 복제 │        | 인물 · ◀ 왼쪽 보기 · 맞춤 F ·      │   이름 · 머리에서  │
│               │          인물과 함께                       │   X·Y · 길이 · 방향│
│ 그림 목록      ├───────────────────────────────────────────┤  그림을 골랐으면   │
│  (이 이모지를  │ 수명의 띠 — 움직임 가져오기 ▾ · + 등장/머묾/  │   이름 · 그림 파일 │
│   이루는 조각) │   퇴장 · 게임처럼 재생 / 색 띠              │   · 자리 · 크기 ·  │
│  그림 추가 ·   │ 타임 슬라이더 · 재생 단추 · 레인지 슬라이더   │   회전 · …        │
│  삭제 · ▲ ▼   ├───────────────────────────────────────────┤  키 놓기 단추      │
│               │ 그래프 / 도프 시트                          │                 │
└───────────────┴───────────────────────────────────────────┴─────────────────┘
```

- 이모지를 고르거나 만들면 저절로 이모지 모드가 된다. 모드를 바꾸면 반대쪽의 선택이 풀린다.
- 패널 사이의 경계를 끌어 크기를 바꾼다. 모드 · 크기 · 창의 자리는 다음에 열 때 그대로다.

# 캐릭터 모션

## 3. 캐릭터 모션 — 첫 모션

**있는 것으로 시작하기(2분)**

1. 왼쪽 모션 칸의 콤보에서 `끄덕`을 고르고 **프리셋에서 추가**. 모션 `nod`가 생긴다. (프리셋: 끄덕 · 젓기 · 깡충 · 움찔 · 떨림 · 숙임 · 바운스 · 호흡 · 돌아서기)
2. **Alt+`** — 처음부터 재생한다. **Alt+Q**는 재생 / 멈춤.
3. 아래 **그래프** 탭에서 키를 **가운데 단추(MMB)로 끌어** 옮긴다. 놓는 순간 뷰포트가 따라오고 **Ctrl+Z**로 돌아온다.
4. **다른 이름으로…** → 저작본으로 저장. **motions.json 내보내기…** → 게임이 읽는 파일.

**처음부터 만들기**

1. **모션 추가** — 이름 `motion` · 길이 1초 · 종료 처리 `복원`으로 생긴다. 오른쪽 **모션** 탭에서 이름(영문 소문자 · 숫자 · `_`) · 길이 · 종료 처리 · 재생 기준을 바꾼다.
2. 왼쪽 하이어아키에서 `s1 › 연기 · 상대값 › 몸` 같은 **컨트롤러**를 누른다. 오른쪽 **채널 박스**에 그 손잡이의 값(좌우 · 상하 …)이 보인다.
3. 뷰포트 위 도구 띠의 **● Auto Key**를 켠다. 타임 슬라이더를 6프레임으로 옮기고 채널 박스의 값에 `30`을 넣고 Enter — 키가 생긴다. 12프레임에서 `0` Enter.
4. 뷰포트에서 **W**(이동) · **E**(회전) · **R**(크기) 손잡이를 끌어도 같다.
5. 그래프에서 키를 전부 고르고 **flat**으로 탄젠트를 평평하게. 문제 칸이 비면 내보낸다.

### 종료 처리와 재생 기준

| 항목 | 값 | 뜻 |
|---|---|---|
| 종료 처리 | **복원**(restore) | 끝나면 시작 자세로 돌아간다 — 끄덕 · 깡충. 마지막 키가 0(크기는 1)이 아니면 끝에서 튄다(알림 △) |
| 종료 처리 | **유지**(commit) | 마지막 키의 자세가 남는다 — 숙인 채 있기 · 돌아선 채 있기 |
| 재생 기준 | **상대값**(relative) | 키를 "지금 자세에서 얼마나"로 읽는다. 연기는 이것으로 만든다 |
| 재생 기준 | **절대값**(absolute) | 키를 "그 값으로"로 읽는다. 자리 · 깊이 컨트롤러에 첫 키를 놓으면 저절로 이쪽이 된다 |

재생 기준은 툴이 미리볼 때 쓰는 것이고 **파일로 나가지 않는다** — 게임에서는 대본의 `<<motion 슬롯 이름 relative|absolute>>`가 정한다.

## 4. 컨트롤러와 키

리그의 노드를 몰라도 되게 **컨트롤러**(손잡이)로 만진다.

| 묶음 | 손잡이 | 뜻 |
|---|---|---|
| **연기 · 상대값** | 몸(좌우 · 상하) · 기울기 · 발 기준 회전 · 떨림 · 크기 · 방향 | 모션은 여기서 만든다. 캐릭터가 어디에 서 있든 같은 움직임이 난다 |
| 자리 · 절대값 | 자리(X · Y) · 슬롯 기울기 · 배율 | 무대에서의 배치. 보통은 모션이 아니라 씬 탭의 "시작 배치"로 둔다 |
| 깊이 · 절대값 | 깊이 슬라이더 0‥40 (가까움 = 20) | 놓으면 배율과 높이를 한 번에 굽는다(되돌리기 한 번) |

- **W / E / R**은 기본 손잡이(몸 · 발 기준 회전 · 크기)로 간다. 다른 손잡이는 하이어아키나 채널 박스에서 고른다.
- 노드를 직접 보려면 설정의 **리그 노드 보기**.

**키를 놓는 길**

| 길 | 하는 일 |
|---|---|
| **Auto Key 켜고** 뷰포트에서 끌기 · 채널 박스에 값 넣기 | 바뀐 성분에 지금 프레임의 키 |
| **Auto Key 끄고** 끌기 | **키 없는 포즈**(주황)로 남는다 — **S**로 키를 놓고, **Esc**로 버린다. 타임 슬라이더를 옮기면 포즈는 사라진다(되돌리기로 돌아온다) |
| **S** | 포즈가 없으면 고른 컨트롤러의 지금 값 전부를 키 |
| 채널 박스 값 옆의 **●** | 그 성분만 키 |
| 그래프에서 곡선을 고르고 **I** · 더블클릭 | 그 곡선의 그 시각에 키 끼우기 |

채널 박스 값의 색: 빨강 = 이 프레임에 키 · 연한 빨강 = 다른 프레임에 키 · 주황 = 키 없는 포즈.

값을 넣고 **Enter**를 누르면 포커스가 뷰포트로 간다 — 그 뒤의 Ctrl+Z는 문서 되돌리기다(글 칸 안에서는 글자 되돌리기).

### 뷰포트

| 조작 | 뜻 |
|---|---|
| 휠 · **MMB / RMB 드래그** · **F** | 확대 · 보기 이동 · 처음 자리로. 화면만 바뀐다 |
| 클릭 | 오브젝트 고르기 |
| **Q / W / E / R** | 선택 / 이동(화살표) / 회전(고리) / 크기(끝의 상자). 축 끝은 한 축만, 가운데는 자유 |
| **S** · **Esc** | 키 놓기 · 포즈 버리기 |

격자는 1칸 40px, 굵은 선은 5칸. 무대 틀 밖도 그대로 그리고 화면에 안 잡히는 바깥은 회색으로 덮인다.

## 5. 그래프 에디터

마야의 그래프 에디터와 같다. 왼쪽이 채널 목록(컨트롤러 › 성분), 위가 툴바, 가운데가 곡선이다.

| 조작 | 뜻 |
|---|---|
| 클릭 · Shift+클릭 · 빈 데서 드래그 · Ctrl+드래그 | 키 고르기 · 더하기 · 상자 · 올가미 |
| 곡선 클릭 | 곡선 고르기 |
| 곡선을 고른 채 **MMB 클릭** · 더블클릭 · **I** | 그 시각에 키 끼우기 |
| **MMB 드래그** | 고른 키 옮기기(시간 · 값). Shift = 한 축만 |
| 고른 키 곁 **RMB 드래그** · 빈 데 **RMB 드래그** | 처음 움직인 축으로만 옮기기 · 보기 이동 |
| **W** · **R** · **Q** | 이동 툴 · 늘이기 툴 · 선택 툴(LMB로 끈다) |
| **리전** | 상자가 남는다 — 안 = 옮기기, 좌우 모서리 = 시간 늘이기, 상하 = 값 늘이기 |
| 탄젠트 손잡이(고른 키 양쪽의 흰 선) | 끝을 끌어 기울기 |
| **auto · spline · linear · flat · plateau** · 끊기 · 붙이기 (**Ctrl+1…6**) | 고른 키의 탄젠트 |
| 버퍼 찍기 · 바꾸기 · 지우기 (**Ctrl+B** · **Ctrl+Shift+B**) | 지금 곡선을 흐린 점선으로 찍어 두고 견준다 |
| 무한(앞 · 뒤) | 범위 밖을 상수 / 사이클 / 사이클+오프셋 / 왕복 / 직선으로 **보기만** 한다(파일은 안 바뀐다) |
| 값 칸에 `+=3` `-=1` `*=2` `/=2` | 고른 키 전부에 그만큼. 숫자만 쓰면 그 값으로 |
| **Ctrl+C / X / V** · **Delete** | 복사 · 잘라내기 · 지금 프레임에 붙여넣기 · 지우기 |
| 휠(Ctrl = 시간만 · Shift = 값만) · **Alt+MMB** · **Alt+RMB** | 확대 · 보기 이동 · 끌어서 확대 |
| **A** · **F** · 재생 범위 | 전체 맞춤 · 고른 것 맞춤 · 재생 범위 맞춤 |
| 시간 스냅 · 값 스냅 | 시간을 프레임에 · 값을 정수에 붙인다 |
| **종류별 칸** | 자리 · 크기 · 회전을 종류마다 한 칸씩 나눠 그린다(값의 크기가 달라 한 눈금에서는 작은 것이 깔린다) |

**탄젠트의 종류** — flat: 그 키에서 멈췄다 간다(가장 무난) · auto: 이웃을 보고 부드럽게 · linear: 직선 · spline: 이웃을 잇는 곡선 그대로(넘칠 수 있다) · plateau: 넘치지 않게 누른다 · step: 계단(이모지에만).

**채널 목록** — 컨트롤러 이름을 누르면 그 컨트롤러를 고르고 그 곡선만 보인다(Shift / Ctrl로 더하기). 성분을 누르면 그 곡선만. 줄 오른쪽의 🔓 · 🔊 · × = 잠금 · 끄기 · 지우기. 아래 "키 없음" 줄의 **＋**는 그 채널에 키를 놓는다.

## 6. 도프 시트와 타임 슬라이더

**도프 시트** — 키를 시간으로만 다룬다. 그래프와 선택이 하나다.

| 조작 | 뜻 |
|---|---|
| 블록 클릭 · Shift · 상자 | 고르기. 요약 줄의 블록 하나는 그 밑의 키 전부 |
| 블록 드래그 · Alt+드래그 · **Ctrl+D** | 시간 옮기기 · 복제 · 한 프레임 뒤에 복제 |
| 범위 띠의 양끝 | 시간 늘이기 |
| 성분 줄 더블클릭 · **Delete** | 그 시각에 키 · 지우기 |
| 눈금자 클릭 · 휠 · MMB · **A** | 스크럽 · 확대 · 보기 이동 · 전체 맞춤 |

**타임 슬라이더 · 레인지 슬라이더**

| 조작 | 뜻 |
|---|---|
| 클릭 · 드래그 | 스크럽(프레임에 붙는다) |
| **Shift+드래그** | 빨간 범위 고르기 |
| 범위 안 **MMB 드래그** · 범위 양끝 | 범위의 키 옮기기 · 시간 늘이기 |
| 범위 밖 **MMB 드래그** | 지금 포즈를 든 채 시각만 옮긴다 → **S**로 그 프레임에 키(포즈 복사) |
| 오른쪽 단추 | 키 복사 · 붙여넣기 · 지우기 · 재생 범위 · 재생 모드(한 번 / 루프 / 왕복) · 속도 |
| 레인지 바 끌기 · 양끝 · 더블클릭 | 재생 범위 옮기기 · 크기 · 전체 ↔ 직전 |
| 길이 칸 | 모션의 길이 |

## 7. 트윈머신

툴바의 **트윈머신**이 작은 창을 띄운다. 마야의 tweenMachine처럼 **앞 키와 뒤 키 사이의 값**을 골라 지금 프레임에 키로 놓는다(사이 포즈). 창은 본 창 위에 떠 있고, 띄운 채 뷰포트 · 그래프를 그대로 만진다.

1. 컨트롤러를 고르고 두 키 **사이의 프레임**으로 간다. 창의 첫 줄이 무엇에, 어느 키와 어느 키 사이에 놓이는지 적는다.
2. **슬라이더**를 끈다 — 0%는 앞 키의 값, 100%는 뒤 키의 값. 끄는 동안 화면이 따라오고, 놓으면 되돌리기 한 칸이다. **단추**(0 · 25 · 33 · 50 · 67 · 75 · 100)는 누르면 바로 놓인다.
3. **오버슈트**를 켜면 −50 ~ 150%까지 간다 — 100% 위는 뒤 키를 지나치는 것, 0% 아래는 반대쪽으로 먼저 가는 예비 동작.

- 대상은 **고른 컨트롤러**다. 포즈 전체에 놓으려면 **"고른 컨트롤러만이 아니라 모션 전체에"**를 켠다. 그래프 목록에서 곡선을 골랐으면 그것만.
- 비율은 값의 비율이다(시간이 아니다). 그 프레임의 앞과 뒤에 키가 있는 곡선에만 놓인다.
- 키 없는 포즈(주황)를 들고 있었으면 버리고 키가 그 자리를 차지한다. 클립을 보는 중에는 쓰지 않는다.
- 이모지에서도 같은 창을 쓴다 — 대상은 고른 그림들(안 골랐으면 이모지 전체).

## 8. 씬 — 캐릭터를 세우는 자리

씬은 모션을 **보는 자리**다. 저작본에 남고 내보내지지 않는다. 오른쪽 **씬** 탭이 고른 오브젝트의 배치다(모션의 키가 아니다).

| 항목 | 뜻 |
|---|---|
| 자리(place) × focus | 가슴(기본) · 얼굴 등의 점이 화면의 그 지점(center · left · right · top · bottom · tl · tr · bl · br)에 오게 세운다 |
| Layer · Stage · 보이기 | 깊이 층(far … close) · 무대(Stage00~02) · 숨기기 |
| 시작 배치(접힘) | 자리를 잡은 뒤 그만큼 더 — 오프셋 X/Y · 회전 · 배율 |
| 카메라(샷)(접힘) | 멈춘 zoom · pan. 구도를 잡아 놓고 모션을 본다. 키는 없다 — 이 툴은 카메라를 움직이지 않는다 |

- 하이어아키 아래의 **초상 PNG…**로 고른 캐릭터의 초상 그림을 넣는다(없으면 자리표시 사각형).
- 하이어아키의 **+ 캐릭터 리그**(Ctrl+Shift+N)로 캐릭터를 더한다. id는 `s1` · `s2` …, **F2**로 바꾼다. 오른쪽 단추: 이름 바꾸기 · 복제(Ctrl+D) · 삭제(Del) · 숨기기 · 레이어.
- 실제 리그로 보려면 툴바 **리그 덤프…**로 런타임의 `ExportedTuning/rig-schemas.json`을 싣는다. 옆의 깊이 · focus · 기준 해상도 · 컨트롤러 표도 같이 실린다.
- **유니티 쪽 리그가 바뀌었을 때** — 바뀐 덤프로 열면 문제 칸에 무엇이 달라졌는지 나온다. 이름만 바뀐 노드는 **이름 바꾸기를 따라간다**로 한 번에 고치고, 다 확인했으면 **이 스키마로 맞춘다**. 사라진 노드를 쓰는 모션은 그 채널을 지울 때까지 내보내지 못한다.

## 9. 모션 겹치기와 굽기 — 연출 클립

모션 여럿을 시간차로 놓아 **한 캐릭터에 겹쳐**(숙이면서 끄덕이기) 보고, 마음에 들면 **구워서 모션 하나**로 만든다. 여러 캐릭터를 같이 세워 타이밍을 보는 데도 쓴다.

1. 모션들을 만들어 둔다. 왼쪽 **클립 추가** → 오른쪽 **클립** 탭.
2. 뷰포트에서 캐릭터를 고르고 **배역 추가** — 그 캐릭터가 배역을 맡고 트랙이 하나 선다.
3. 클립을 고르면 그래프 위에 **타임라인**이 선다. 트랙의 빈 곳을 오른쪽 단추 → **모션 놓기**. 블록을 끌어 시각과 트랙을 옮긴다.
4. 겹치려면 같은 캐릭터로 **배역을 하나 더** 만들거나 **트랙 추가** — 그 줄에 다른 모션을 놓는다.
5. 재생해 본다. 고칠 것은 블록을 눌러 바로 아래 그래프에서 고친다(클립을 떠나지 않는다). 타임 슬라이더를 그 블록 안으로 옮기면 뷰포트에서 포즈를 잡아도 그 블록의 모션에 키가 놓인다.
6. 빈 줄을 오른쪽 단추 → **새 모션으로 굽기** — `클립이름_캐릭터` 모션이 왼쪽 목록에 생긴다. 그 모션 하나가 같은 움직임을 낸다.

| 조작 | 뜻 |
|---|---|
| 블록 클릭 · 드래그 · 더블클릭 | 고르기 · 옮기기(가로 시각 · 세로 트랙) · 그 모션만 열기 |
| 블록 오른쪽 단추 | 상대값 / 절대값 · 이 블록만 따로(모션 복제) · 끄기 · 이어서 한 번 더 · 삭제 |
| 빈 줄 오른쪽 단추 | 모션 놓기 · 배역 끄기 · 새 모션으로 굽기 · 트랙 추가 / 삭제 |
| **M** | 고른 블록 끄기 / 켜기 — 파일에 남는다. 하나씩 꺼 가며 견준다 |
| 줄 머리의 🔊 | 그 배역 끄기 / 켜기 — 보기만(파일은 안 바뀐다). 끈 배역은 굽지 않는다 |
| **Ctrl+D** · **Delete** | 끝에 이어서 한 번 더 · 삭제 |
| 블록 칸의 **반복(번)** | 그 모션을 이어서 몇 번 — 유지 모션은 돌 때마다 쌓이고 복원 모션은 매번 처음 자세에서 |

- 모션은 **함께 쓰는 것**이다 — 고치면 그 모션을 쓰는 블록이 다 바뀐다(블록 칸이 "n곳에서 쓰인다"고 알린다). 이 블록만 다르게 하려면 **이 블록만 따로**.
- 유지(commit) 모션이 끝나면 그 자세가 남아 뒤의 블록이 거기서 시작한다.
- 한 캐릭터의 **같은 손잡이**를 쓰는 블록은 시간이 겹칠 수 없다(빨간 테두리). 다른 손잡이를 쓰는 모션끼리 겹친다.
- 클립은 내보내지지 않는다 — 구운 모션이 `motions.json`으로 나간다.

## 10. 내보내기와 문제 칸

- **motions.json 내보내기…** — 툴바에서 그 왼쪽의 **내보내기 범위**(전체 / 이 리그만 / 이 오브젝트가 입는 모션만)의 모션이 나간다.
- 아래 문제 칸: 빨강 **⚠**는 **막는 문제**(내보내지 못한다), 노랑 **△**는 **알림**(내보내진다).
- 줄마다 **고쳐 주는 단추**가 있다(되돌리기 한 번): 끝 키를 길이로 · 길이를 마지막 키에 · 길이 자리에 키 넣기 · 마지막 키를 중립값으로 · 첫 키를 0으로 · 끝을 유지로 · 이름 고치기.

모션의 규칙: 이름은 영문 소문자 · 숫자 · `_` / 성분마다 키 둘 이상 / 첫 키는 0프레임, 마지막 키는 길이의 끝 / 캐릭터 모션에는 계단 키 · 투명도 · 그림 채널을 쓰지 않는다.

**motions.json 가져오기…**는 게임의 `motions.json`을 읽어 모션으로 들인다(고쳐서 다시 내보낸다).

# 이모지

## 11. 이모지 — 첫 이모지

이모지는 **그림 여러 장이 타임라인 하나**(초당 24프레임)를 함께 쓰는 것이다. 인물의 머리 곁에 뜬다.

먼저 만들어진 것을 보려면 **열기…**로 `examples/emoji/emoji-examples.motion-authoring.json`(견본 셋 — `star` · `question` · `twinkle`).

1. 툴바의 **이모지**로 모드를 바꾸고 왼쪽 **이모지 추가** — **새 이모지** 창이 뜬다.
2. 셋을 정한다.

| 칸 | 뜻 |
|---|---|
| 이름 | 영문 소문자 · 숫자 · `_`. 대본의 `<<emoji 누구 이름>>`이 부르는 이름 |
| 1. 그림 | PNG를 창에 끌어다 놓거나 **그림 고르기…**(여러 장). 한 장이 그림 하나가 된다. 목록의 순서가 그리는 순서(아래가 위) — **▲ ▼**로 바꾼다 |
| 2. 어떻게 뜨는가 | **한 번 재생하고 사라진다** / **머문다**(`<<emoji_off>>`로 내릴 때까지) |
| 3. 움직임 | 등장 · 머묾 · 퇴장의 움직임을 고른다(없음도 된다) |

3. **만들기** — 움직이는 이모지가 생긴다(되돌리기 한 칸). **빈 이모지로 시작**은 그림도 움직임도 없이 빈 그림 `body` 하나.
4. **▶**(Alt+Q)로 재생해 보고, 띠 윗줄의 **게임처럼 재생**으로 등장 → 머묾 → 퇴장을 본다.
5. 고친다 — 뷰포트에서 그림을 끌고([13절](#13-뷰포트에서-만지기)), 띠의 끝을 끌어 길이를 맞추고([12절](#12-수명--등장--머묾--퇴장)), 그래프에서 곡선을 다듬는다.
6. 툴바 **emojis.json 내보내기…**.

**고른 것이 오른쪽과 그래프를 정한다.** 왼쪽에서 **이모지**를 누르면 오른쪽은 이모지의 값(이름 · 머리에서 X · Y · 길이 · 방향)이고 그래프는 전부를 보인다. **그림**을 누르면 오른쪽은 그 그림의 값(이름 · 그림 파일 · 자리 · 크기 · 회전 · 뒤집지 않기 · 그림 넘기기)이고 그래프는 **그 그림의 곡선만** 보인다.

**화면의 말과 파일의 말**

| 화면 | 파일(`AUTHORING-FILES.md`) |
|---|---|
| 그림 | `rigs[]` — 그래프 줄의 `body`는 `body/EmojiRig_Image` |
| 이모지 전체 | `Emoji_Offset` |
| 머리에서 X · Y | `offsetX` · `offsetY` |
| 자리 · 크기 · 회전 · 투명도 · 그림 | `position` · `scale` · `euler` · `alpha` · `image` |
| 인물의 방향을 따르지 않기 / 이 그림은 뒤집지 않기 | `fixedSide` / `upright` |

## 12. 수명 — 등장 · 머묾 · 퇴장

타임라인의 **구간**을 등장 · 머묾 · 퇴장에 **이으면** 게임이 등장 한 번 → 머묾 되풀이 → (내리면) 퇴장으로 돌린다. 머묾이 없으면 타임라인 전체를 한 번 재생하고 사라진다.

뷰포트와 타임 슬라이더 사이가 **수명의 띠**다.

| | |
|---|---|
| 윗줄의 글 | 이 이모지가 어떻게 사는가 |
| **+ 등장 · + 머묾 · + 퇴장** | 아직 없는 자리에 구간을 놓고 잇는다 |
| 색 띠 | 등장(초록) · 머묾(노랑) · 퇴장(파랑). 점선은 어디에도 잇지 않은 구간 |
| 띠의 끝 끌기 / 몸통 끌기 | 시작 · 끝을 / 통째로 옮긴다. 프레임에 붙는다 |
| 띠에서 오른쪽 단추 | 풀기(구간은 남는다) · 구간 지우기 |
| **게임처럼 재생** · 머묾 n 바퀴 | 수명을 게임과 같은 계산으로 돌린다. 머묾을 몇 바퀴 돈 뒤 내릴지 |
| **움직임 가져오기 ▾** | 미리 만든 움직임의 키를 넣는다(아래) |

**움직임 가져오기**

| 자리 | 움직임 |
|---|---|
| 등장 | **튀어나오기** · **서서히 나타나기** |
| 머묾 | **두근거리기** · **흔들기** |
| 퇴장 | **위로 사라지기** · **줄어들며 사라지기** |

- **대상**은 고른 그림들이다. 안 골랐으면 이모지 전체.
- **넣을 곳**은 띠에서 고른 구간, 없으면 그 움직임의 자리의 구간이다(그 자리가 비었으면 구간도 함께 놓인다). 메뉴의 줄마다 어디에 넣는지 적혀 있다.
- 넣은 것은 **그냥 키**다 — 마음대로 고친다. 되돌리기 한 칸.

구간의 경계에서 값이 이어져야 튀지 않는다 — 머묾은 되풀이되니 **처음과 끝의 모습이 같아야** 하고, 등장의 끝과 퇴장의 처음이 머묾의 모습과 같아야 한다.

길이는 오른쪽의 **길이(프레임)**. 구간의 이름과 프레임을 숫자로 적으려면 오른쪽의 **구간과 잇기 (숫자로)**를 펼친다 — 잇지 않은 구간을 더 두거나 한 구간을 두 자리에 잇는 것도 거기서 한다.

## 13. 뷰포트에서 만지기

이모지는 인물의 **머리**에 서서 보인다(십자가 머리의 자리). 도구 띠(또는 **Q · W · E · R**)로 도구를 고르고 그림을 눌러 끈다.

| | Auto Key 꺼짐 | Auto Key 켜짐 |
|---|---|---|
| 그림을 끌면 | **기본값**이 바뀐다 — 자리 · 크기 · 회전(오른쪽의 칸과 같다) | **지금 프레임에 키**가 놓인다 |
| 이모지 전체를 끌면 | 머리에서의 자리가 바뀐다 | 이모지 전체의 키가 놓인다 |

- 뷰포트 왼쪽 아래의 글이 지금 끌면 무엇이 바뀌는지 적는다("이동(W) · body: 끌면 9프레임에 키").
- **이모지 전체**를 만지려면 왼쪽 목록에서 그 이모지를 누른다(이모지를 처음 고르면 이 상태다).
- **빈 데를 누르면 선택이 전부 풀린다** — 고른 것이 없으면 끌어도 아무것도 옮겨지지 않는다.
- **여럿 고르기** — Shift(또는 Ctrl)로 더하거나 빼고, 빈 데서 끌면 상자로 고른다. 함께 끌리고 **S**가 전부를 키한다(되돌리기 한 칸).
- **무리째 돌리기 · 늘이기** — 여럿을 고르고 **E**(회전)하면 가운데 점을 축으로 무리 전체가 돈다(별 셋이 원을 그리며 돈다). **R**(크기)도 가운데 점에서 벌어진다.
- 그림의 투명한 데는 눌러도 맞지 않는다. 겹친 자리에서 다시 누르면 그 밑의 그림으로 넘어간다.
- **S**는 끌지 않고 지금 값을 키한다.

도구 띠의 오른쪽은 보기의 단추다.

| 단추 | 뜻 |
|---|---|
| **인물** | 인물(초상 · 실루엣)을 보이거나 감춘다 |
| **◀ 왼쪽 보기** | 왼쪽을 보는 인물에게 뜬 모습을 본다([15절](#15-좌우)). 보기만 — 켠 동안에는 그림의 기본 자리를 끌어 옮기지 못한다 |
| **맞춤 F** · **인물과 함께** | 그림에 맞춰 / 인물의 머리까지 같이 보이게 |

머리의 자리는 캐릭터마다 다르고 런타임의 표가 든다. 덤프 옆에 `presets/emoji-locator.json`이 있으면 그 자리로, 없으면 발에서 800px 위로 보인다 — 보기일 뿐 이모지의 값은 바뀌지 않는다.

## 14. 이모지의 키와 그래프

**키 놓기** — 오른쪽 아래의 단추 **자리 · 크기 · 회전 · 투명도 · 그림**. 누르면 그 종류의 지금 값이 지금 프레임에 키로 놓인다. 대상은 단추 위에 적힌 대로 고른 그림들(안 골랐으면 이모지 전체)이다. 투명도와 그림 바꾸기는 뷰포트에서 끌 수 없으니 이 단추로 키를 놓고 그래프에서 값을 바꾼다.

| 종류 | 값 |
|---|---|
| 자리 | 기본 자리에서 얼마나(px) |
| 크기 | 기본 크기 위에서 1이 제 크기 |
| 회전 | 도 |
| 투명도 | 0(안 보임) ~ 1(다 보임) |
| 그림 | 그 그림의 몇 번째 장인가(0부터) — 늘 계단이다 |

- **그림 넘기기**(그림을 골랐을 때 오른쪽) — 장이 여럿이면 "몇 프레임부터 · 몇 프레임마다 · 몇 번"으로 그림 키를 한 번에 깐다. 장은 **그림 더하기…**로 넣는다.
- 그래프의 **step**은 고른 키를 계단으로 만든다(다음 키까지 그 값으로 멈춘다).
- **종류별 칸**(기본 켜짐)이 자리 · 크기 · 회전 · 투명도를 칸마다 제 눈금으로 그린다.
- 그림의 **기본 자리 · 크기 · 회전**(오른쪽의 칸)은 키가 아니다 — 그 그림을 이 이모지에서 어디에 얼마만 하게 두는가다. 키는 그 위에 얹힌다.
- 트윈머신([7절](#7-트윈머신))도 쓴다.

## 15. 좌우

이모지는 **오른쪽을 보는 인물**을 기준으로 만든다. 인물이 왼쪽을 보면 게임이 이모지를 통째로 거울에 비춘다 — 따로 만들지 않는다. **◀ 왼쪽 보기**로 확인한다.

| 칸 | 뜻 |
|---|---|
| 인물이 돌아서도 이 그림은 뒤집지 않기(그림의 칸) | 물음표 · 느낌표 · 글자처럼 거울에 비치면 안 되는 그림. 그림과 그 키는 만든 그대로 보이고 기본 자리만 거울 쪽으로 간다 |
| 인물의 방향을 따르지 않기(이모지의 칸) | 인물이 뒤집혀도 만든 쪽 그대로 선다 — 머리 위 한가운데에 뜨는 것 |

"뒤집지 않기"를 켠 그림이 바깥으로 흐르는 키를 가졌다면 뒤집힌 인물에게는 안쪽으로 흐른다(키가 만든 그대로 보이기 때문이다). 그런 움직임은 **이모지 전체**의 키로 잡는다 — 그것은 뒤집힌다.

## 17. 설정과 파일

- **설정…** — 리그 노드 보기 · 무대 뼈대 보기 · 시간 스냅 간격(1프레임 기본) · 새 키의 탄젠트 · 시간 표시(프레임 / 초) · 자동 저장 간격. 바꾸는 즉시 적용된다.
- 설정 파일: `%APPDATA%\ked-motion-tool-characterRig\settings.json`.
- **자동 저장**: 문서 옆 `<이름>.autosave.motion-authoring.json`(기본 5분, 바뀐 것이 있을 때만). 원래 파일은 건드리지 않는다.
- 이모지의 그림은 **문서 기준의 경로**로 적힌다 — 저작본과 그림을 같이 옮긴다. 게임은 그림을 파일 이름으로 찾는다.
- 창 없이 확인 · 내보내기: `mt`(`AUTHORING-FILES.md` §2).

## 18. 막혔을 때

| 증상 | 까닭 · 할 일 |
|---|---|
| 내보내기가 안 된다 | 문제 칸에 ⚠가 있다. 줄의 단추로 고치거나 키를 고친다 |
| 키를 놓았는데 성분이 하나만 생겼다 | 바뀐 성분만 키가 된다. 전부 놓으려면 **S** |
| 끌었는데 주황색으로만 남는다 | Auto Key가 꺼져 있다 — **S**로 키, **Esc**로 버림. 또는 Auto Key를 켠다 |
| 모션이 끝에서 튄다 | 종료 처리가 복원인데 마지막 키가 0이 아니다 — 마지막 키를 0으로, 또는 유지로 |
| 모션이 목록에서 흐리다("안 맞음") | 고른 오브젝트의 리그가 그 모션의 리그와 다르다 |
| Ctrl+Z가 글자만 지운다 | 글 칸 안이다. Enter로 확정하면 그 뒤는 문서 되돌리기 |
| 이모지를 끌어도 안 움직인다 | 고른 것이 없다 — 그림을 누르거나 왼쪽 목록에서 이모지를 누른다. 또는 "왼쪽 보기"가 켜져 있다 |
| 이모지의 그림이 사각형으로 보인다 | 그림 파일이 그 경로에 없다 — 그림을 고르고 **그림 더하기…**로 다시 넣는다 |
| 머묾이 돌 때마다 튄다 | 머묾 구간의 처음과 끝의 모습이 다르다 |
| 블록에 빨간 테두리 | 같은 캐릭터의 같은 손잡이를 쓰는 블록이 겹쳤다 — 시각을 옮긴다 |
| 상태 줄에 "리그 덤프가 없어 내장본으로" | 문서가 기억한 덤프의 경로에 파일이 없다. 다시 싣거나 내장본으로 계속한다 |
| 문제 칸에 "스키마가 다르다" | 유니티 쪽 리그가 바뀌었다 — [8절](#8-씬--캐릭터를-세우는-자리) |
