# ked-motion-tool 사용법

애니메이터·연출자용 안내. 설치부터 `motions.json` 내보내기까지, 그리고 화면별 조작 전부.
키 하나하나의 전체 표는 툴 안의 **단축키 (F1)** 창에도 있다.

## 1. 설치와 실행

| 방법 | 절차 |
|---|---|
| 소스에서 실행 | .NET 10 SDK 설치 → 저장소 루트에서 `dotnet run --project src/Mt.App/Mt.App.csproj` |
| 빌드만 | `dotnet build KedMotionTool.sln --configuration Release` |

처음 열면 **내장 리그**(유니티 덤프의 사본)로 캐릭터 `s1`이 선 빈 문서가 뜬다. 덤프 파일이나 초상 PNG가 없어도 바로 모션을 만들 수 있다. 상태 줄에 `내장 리그(…)`가 보이면 정상이다.

설정 파일은 `%APPDATA%\ked-motion-tool\settings.json`에, 자동 저장은 문서 옆 `<이름>.autosave.motion-authoring.json`에 남는다.

## 2. 화면 구성

```
┌ 툴바: [캐릭터 모션 | 이모지] · 새로 · 열기… · 최근… · 저장 · 다른 이름으로… · 리그 덤프… · motions.json 가져오기… · 내보내기… · 되돌리기 · 다시하기 · 설정… · 단축키 (F1)
├───────────────┬──────────────────────────────────┬──────────────────┐
│ 씬 — 오브젝트  │ 뷰포트 (무대·격자·초상·매니퓰레이터)  │ 인스펙터 탭 넷     │
│   하이어아키   │                                  │  채널 박스 (기본)  │
│ 모션 목록      │ 타임 슬라이더 · 트랜스포트          │  씬              │
│ 모션 추가      │ 레인지 슬라이더 · 재생 모드 · Auto Key│  모션            │
│ 프리셋에서 추가 ├──────────────────────────────────┤  클립            │

├───────────────┴──────────────────────────────────┴──────────────────┤

```

위는 **캐릭터 모션** 모드의 화면이다. 툴바 맨 앞의 **캐릭터 모션 | 이모지**가 작업 모드를 고른다 — 화면에는 그 일에 쓰는 것만 보인다.

| 모드 | 왼쪽 | 오른쪽 | 툴바의 내보내기 |
|---|---|---|---|
| 캐릭터 모션 | 씬 · 모션 · 클립 | 채널 박스 · 씬 · 모션 · 클립 탭 | `motions.json` 가져오기 · 내보내기 |
| 이모지 | 이모지 목록 · 그 이모지의 그림 목록 | 고른 것의 값(이모지 또는 그림) — 탭이 아니다 | `emojis.json` 내보내기 |

**이모지** 모드의 화면:

├───────────────┬───────────────────────────────────────────┬─────────────────┐

│  (이 이모지를  │ 타임 슬라이더 · 트랜스포트 · 레인지 슬라이더    │   이름 · 그림 파일 │

가운데(뷰포트 · 슬라이더 · 그래프 · 도프 시트)는 두 모드가 함께 쓴다. 이모지를 고르거나 만들면 저절로 이모지 모드가 되고, 툴바에서 모드를 바꾸면 반대쪽의 선택이 풀린다. 모드는 다음에 열 때 그대로다.

패널 사이의 스플리터를 끌어 크기를 바꾼다. 폭과 비율은 다음에 열 때 그대로다.

## 3. 10분 안에 한 번 해 보기

1. **프리셋에서 시작**: 왼쪽 모션 칸의 콤보에서 `끄덕`을 고르고 **프리셋에서 추가**. 모션 `nod`가 생긴다.
2. **Alt+`** — 처음부터 재생. 캐릭터가 끄덕인다. **Alt+Q**는 재생/일시정지.
3. 아래 **그래프** 탭에서 키를 **MMB 드래그**로 옮겨 본다. 놓는 순간 뷰포트가 따라오고 **Ctrl+Z**로 돌아온다.
4. **도프 시트** 탭에서 블록을 끌면 시간만 옮겨진다.
5. **다른 이름으로…** → `*.motion-authoring.json`(저작 원본). **motions.json 내보내기…** → 런타임이 읽는 산출물. 문제 칸이 비어 있을 때만 나간다.

실제 리그·초상으로 보고 싶으면 **리그 덤프…**로 `ked-stage-runtime/ExportedTuning/rig-schemas.json`을, **초상 PNG…**로 `ked-presentation-runtime/Assets/Samples/Portraits/harin/b/01.png` 같은 파일을 싣는다. 덤프 옆의 `base-resolution.json`·`presets/depth.json`·`presets/focus-tuning.json`·`presets/controllers.json`은 자동으로 같이 실린다.

**유니티 쪽 리그가 바뀌었을 때.** 문서는 지을 때의 스키마를 적어 둔다(덤프를 싣거나 저장할 때). 바뀐 덤프로 열면 아래 문제 줄에 "문서를 지을 때와 스키마가 다르다"와 함께 무엇이 달라졌고 무엇이 그것을 쓰는지 나온다.
이름만 바뀐 노드는 **이름 바꾸기를 따라간다**로 한 번에 고치고, 다 확인했으면 **이 스키마로 맞춘다**를 누른다. 사라진 노드를 쓰는 모션은 그 채널을 지우거나 다른 노드로 옮길 때까지 내보내지 못한다.

## 4. 모션을 처음부터 만들기

1. **모션 추가** — 이름 `motion`, 선택 오브젝트의 리그, 길이 1초, 종료 처리 `복원(Restore)`로 생긴다. 오른쪽 **모션** 탭에서 이름(소문자·숫자·`_`)·길이·종료 처리·재생 기준을 바꾼다.
2. 왼쪽 하이어아키에서 `s1 › 연기 · 상대값 › 몸` 같은 **컨트롤러**를 클릭한다. 오른쪽 **채널 박스**에 그 손잡이의 성분(좌우·상하 등)이 보인다.
3. 하단 줄의 **● Auto Key**를 켠다. 현재 시각을 `0.25`(또는 6프레임)로 두고 채널 박스의 값에 `30` Enter — 채널·성분·키가 한 번에 생긴다. `0.5`에서 `0` Enter.
4. 뷰포트에서 **W**(이동)·**E**(회전)·**R**(배율) 손잡이를 끌어도 같다. Auto Key가 꺼져 있으면 끈 결과는 **키 없는 포즈**(주황)로 남고, **S**로 키를 놓거나 **Esc**로 버린다.
5. 그래프에서 키를 전부 고르고 **flat**(Ctrl+2)으로 탄젠트를 평평하게. 문제 칸이 비면 내보낸다.

### 종료 처리와 재생 기준

| 항목 | 값 | 뜻 |
|---|---|---|
| 종료 처리 | 복원(Restore) | 길이를 지나면 시작 상태로 돌아간다. 마지막 키가 중립값이 아니면 경고(△)만 — 끝에서 튄다 |
| 종료 처리 | 유지(Commit) | 마지막 키가 남는다(예: `돌아서기`는 방향 ×−1이 남는다) |
| 재생 기준 | 상대값(Relative) | 툴이 키를 "시작값 + 키"(배율은 ×)로 읽는다. 파일에는 안 나간다 — 실제 뜻은 대본의 `<<motion slot 이름 relative\|absolute>>`가 정한다 |
| 재생 기준 | 절대값(Absolute) | 키 그대로. 자리·깊이 컨트롤러에 키를 놓으면 자동으로 이쪽이 된다 |

### 컨트롤러 세 묶음

| 묶음 | 손잡이 | 뜻 |
|---|---|---|
| 자리 · 절대값 | 자리(X·Y) · 슬롯 기울기 · 배율 | 무대 배치. 보통 모션이 아니라 씬 탭의 "시작 배치"로 둔다 |
| 깊이 · 절대값 | 깊이 슬라이더 0‥40 (close = 20) | 놓으면 배율 X·Y와 깊이 Y를 한 번에 굽는다(되돌리기 한 번) |
| 연기 · 상대값 | 몸(좌우·상하) · 기울기 · 발 기준 회전 · 떨림 · 크기 · 방향 | 모션의 본거지. 어느 자리·깊이에서도 같다 |

W/E/R은 표의 기본 손잡이(몸·발 기준 회전·크기)로 간다. 리거용 **리그 노드 보기**(설정)를 켜면 덤프 노드 26단이 그대로 보인다.

## 5. 뷰포트

| 조작 | 뜻 |
|---|---|
| 휠 · **MMB/RMB 드래그** · **F** | 커서 축으로 확대/축소 · 보기 이동 · 처음 자리(이모지를 보고 있으면 그 그림에 맞춤). 화면만 바뀌고 씬·키는 그대로 |
| LMB 클릭 | 오브젝트 고르기 |
| **Q** / **W** / **E** / **R** | 선택 / 이동(화살표) / 회전(고리) / 배율(끝 상자). 축 끝은 한 축만, 가운데는 자유. 배율은 팔 방향으로 끈 거리 — 팔 하나만큼 밖이 ×2, 안이 0에 가깝고 가운데를 지나도 커지지 않는다 |
| **S** · **Esc** | 키 없는 포즈를 키로 / 버리기. 포즈가 없으면 S는 고른 컨트롤러의 지금 값 전부를 현재 시각에 키 |
| `` ` `` · **Home/End** · **←/→** · **Alt+1/2** | 첫 프레임 · 처음/끝 · 한 프레임(24fps) |
| **Alt+Q** · **Alt+`** | 재생/일시정지 · 처음부터 재생 |

무대 프레임 밖의 오브젝트도 그대로 그리고, 카메라에 안 잡히는 바깥은 회색으로 덮인다. 격자는 1u = 40px(기준 폭/48), 굵은 선 5u.

## 6. 그래프 에디터 (마야 그래프 에디터와 같다)

왼쪽 아웃라이너(컨트롤러·성분), 위 툴바, 플롯(위 눈금자는 프레임, 재생 범위 안은 밝게, 현재 시각은 노란 선).

| 조작 | 뜻 |
|---|---|
| 클릭 · Shift+클릭 · 빈 자리 드래그 · Ctrl+드래그 | 키 선택 · 더하기 · 박스(키가 들면 키만, 커브만 지나면 커브) · 라소 |
| 커브 선 클릭 · Shift+클릭 | 커브 선택(흰색) · 더하기/빼기 |
| 커브를 고른 채 **MMB 클릭** · 더블클릭 · **I** | 그 커브 위, 그 시각에 키 끼우기 |
| **MMB 드래그** | 선택 키 이동(시간·값). 핸들을 골랐으면 핸들 회전. Shift = 축 잠금 |
| 선택 키 둘레 **RMB 드래그** · 빈 자리 **RMB 드래그** | 처음 움직인 축으로만 이동(Shift = 정수 프레임·값 스냅) · 팬 |
| **W** 이동 툴 · **R** 스케일 툴 · **Q** 선택 툴 | LMB 드래그로 이동 · 선택 중심 기준 스케일(오른쪽 = 시간, 위 = 값) · 고르기만 |
| 툴바 **리전** 토글 | 상자가 남는다. 안 = 이동, 좌우 모서리 = 시간 스케일, 상하 = 값 스케일. 다시 누르면 선택 툴로 |
| 탄젠트 핸들(선택 키 양쪽 흰 선) | 끝을 LMB로 끌어 기울기. 박스로 고르면 MMB로 돌린다 |
| 툴바 auto · spline · linear · flat · plateau · 끊기 · 붙이기 · **Ctrl+1…6** | 선택 키 탄젠트(4 = free는 버튼 없음) |
| 툴바 버퍼 찍기/바꾸기 · 지우기 · **Ctrl+B** · **Ctrl+Shift+B** | 보이는 커브를 흐린 점선으로 찍어 두고 지금과 바꾼다 |
| 툴바 무한(앞·뒤) | 상수 / 사이클 / 사이클+오프셋 / 왕복 / 직선 — 보기만(산출물의 끝은 종료 처리) |
| 툴바 값 칸 `+=3` `-=1` `*=2` `/=2` | 선택 키 전부에 상대 적용. 숫자는 절대값 |
| **Ctrl+C / X / V** · **Delete** | 복사 · 잘라내기 · 현재 시각에 붙여넣기 · 삭제 |
| 휠(Ctrl = 시간만, Shift = 값만) · **Alt+MMB** · **Alt+RMB** | 줌 · 팬 · 줌 드래그 |
| **A** · **F** · 툴바 재생 범위 | 전체 맞춤 · 선택 맞춤 · 재생 범위 맞춤 |
| 툴바 시간 스냅 · 값 스냅 | 키 배치·이동·스크럽 시 시간을 간격(기본 1/24초)의 배수에 · 값을 정수에 |

아웃라이너에서 컨트롤러 이름 클릭 = 고르기 + 그 커브만(Shift/Ctrl: 더하기), 성분 클릭 = 그 커브만. 흐린 성분은 키가 없는 것이라 클릭해도 생기지 않는다(키를 놓을 때 생긴다). 성분 행의 × = 그 성분 삭제, 컨트롤러 행의 🔓/🔒 · 🔊/🔇 · × = 잠금 · 뮤트 · 키 전부 삭제.

## 7. 도프 시트

그래프와 **선택이 하나**다.

| 조작 | 뜻 |
|---|---|
| 블록 클릭 · Shift · 박스 | 선택. 요약 행의 블록 하나는 그 밑의 키 전부 |
| 블록 드래그 · Alt+드래그 · **Ctrl+D** | 시간 이동 · 복제 · 한 프레임 뒤에 복제 |
| 범위 띠 양끝 핸들 | 시간 스케일(반대쪽 끝이 기준) |
| 성분 행 더블클릭 · **Delete** | 그 시각에 키 · 삭제 |
| 눈금자 클릭·드래그 · 노드 행 클릭 · 휠 · MMB · **A** | 스크럽 · 접기 · 시간 줌 · 팬 · 전체 맞춤 |

움직인 키가 안 움직인 키의 시각에 닿으면 움직인 키가 이긴다. 시간은 0 아래로 안 내려간다.

## 7-1. 연출 클립 — 여러 캐릭터를 시간차로

1. 씬에 캐릭터를 둘 이상 세우고(왼쪽 `+ 캐릭터 리그`) 모션을 만들어 둔다.
2. 왼쪽 **클립 추가** → 오른쪽 **클립** 탭. 뷰포트에서 캐릭터를 고르고 **배역 추가** — 고른 캐릭터가 그 배역을 맡고 트랙이 하나 선다. 캐릭터마다 되풀이한다.
3. 아래 **타임라인** 탭에서 트랙의 빈 곳을 우클릭 → **모션 놓기**. 블록을 끌어 시각과 트랙을 옮긴다.
4. 재생(▶)하면 모두가 각자의 블록대로 움직인다.
5. **고치기**: 블록을 누르면 타임라인 바로 아래 그래프에 그 모션의 커브가 뜬다. 거기서 키를 고치면 뷰포트의 클립에 바로 보인다 — 클립을 떠나지 않는다.
   같은 모션을 여러 블록이 쓰면 다 같이 바뀐다. 이 블록만 다르게 하려면 블록 우클릭 → **이 블록만 따로**.
   뷰포트에서도 된다: 블록을 고르고 타임 슬라이더를 **그 블록 안**으로 옮기면 캐릭터에 손잡이가 선다 — 끌거나 채널 박스에 값을 넣거나 **S**를 누르면 그 블록의 모션에 키가 놓인다.
6. **견주기**: 블록을 고르고 **M** = 그 블록만 끄기/켜기(파일에 남는다). 줄 머리의 🔊 = 그 배역 전체 끄기/켜기(미리보기에서만).
7. 타임라인과 그래프 사이의 경계를 끌어 높이를 조절한다.

| 조작 | 뜻 |
|---|---|
| 블록 클릭 · 드래그 | 선택 · 이동(가로 시각, 세로 트랙) |
| 블록 우클릭 | 상대값/절대값 · 모션 편집 · 이어서 한 번 더 · 삭제 |
| 빈 줄 우클릭 | 모션 놓기 · 트랙 추가/삭제 |
| 눈금자·빈 곳 · **Ctrl+D** · **Delete** | 스크럽 · 끝에 이어서 · 삭제 |
| 줄 머리의 🔊 | 그 배역 끄기/켜기 — 미리보기에서만 빠진다(파일은 안 바뀐다) |
| 빈 줄 우클릭 → 새 모션으로 굽기 | 그 캐릭터에 얹힌 블록 전부를 모션 하나로 |

**한 캐릭터에 모션을 겹칠 때.** 같은 캐릭터를 맡는 배역을 하나 더 만들면(그 캐릭터를 고르고 배역 추가) 그 캐릭터에 모션을 겹쳐 합성할 수 있다.
마음에 들면 빈 줄을 우클릭해 **새 모션으로 굽기** — `클립이름_캐릭터` 모션이 왼쪽 목록에 생기고, 그 모션 하나가 같은 움직임을 낸다.
끈 배역은 굽지 않으므로, 배역을 꺼 가며 원하는 조합만 구울 수 있다.

유지(commit) 모션이 끝나면 그 값이 남아 뒤 블록이 거기서 시작한다. 한 캐릭터의 같은 노드를 쓰는 블록은 겹칠 수 없다(빨간 테두리).
클립은 아직 저작본에만 저장된다 — `motions.json` 내보내기에는 들어가지 않는다.

## 8. 타임 슬라이더 · 레인지 슬라이더

| 조작 | 뜻 |
|---|---|
| LMB 클릭·드래그 | 스크럽(프레임 스냅) |
| **Shift+LMB 드래그** | 빨간 프레임 범위 선택. 한 프레임만 고르면 그 프레임의 키 선택 |
| 범위 안 **MMB 드래그** · 범위 양끝 LMB | 범위의 키 이동 · 반대쪽 끝 기준 시간 스케일 |
| 범위 밖 **MMB 드래그** | 포즈를 든 채 시각만 이동(점선 테두리). **S**로 그 포즈를 그 프레임에 키 |
| RMB 메뉴 | 키 복사·붙여넣기·삭제·스냅 · 재생 범위를 선택으로/전체로 · 재생 모드·속도 · 키 틱 표시 |
| 레인지 바 끌기 · 양끝 · 더블클릭 | 재생 범위 이동 · 크기 · 전체 ↔ 직전 범위 |
| 길이 칸 | 모션 길이 |
| 재생 표시 연속 / 프레임 맞춤 (24 FPS) | 둘 다 실제 시간. 프레임 맞춤은 가장 가까운 24fps 프레임의 자세만 |

전역 키: **1 / 2** 이전·다음 키, **Shift+W / E / F** 현재 시각의 키 복사·붙여넣기·지우기, **Shift+1 / 2** 인비트윈 빼기·넣기, **Ctrl+Z / Y**(또는 Ctrl+Shift+Z) 되돌리기·다시하기. 창 어디에 포커스가 있든 듣고, 글 입력 칸 안에서만 글자 편집이 우선한다.

## 9. 씬 탭 — 오브젝트 배치 (모션 키가 아니다)

| 항목 | 뜻 |
|---|---|
| 자리(place) × focus | 코어 place 폴드로 focus 점(기본 bust)이 화면 지점(center/left/right/top/bottom/tl/tr/bl/br)에 오게 |
| Layer · Stage · 보이기 | far…close 층, Stage00~02 무대, 숨기기. 그리는 순서는 Stage00 → 02, 그 안에서 far → close |
| 시작 배치(접힘) | 오프셋 X/Y · Rot Z · Scale X/Y — 자리를 잡은 뒤 그만큼 더 간다 |
| 카메라(샷)(접힘) | zoom · pan X/Y. 런타임 `StageZoom_Root`·`StagePan_Root`와 같은 자리, 층마다 패럴랙스. 키는 없다 |

하이어아키의 **+ 캐릭터 리그**(Ctrl+Shift+N)로 오브젝트를 더한다. id는 `s1`·`s2`… 자동, **F2**로 바꾼다. 우클릭: 이름 바꾸기 · 복제(Ctrl+D) · 삭제(Del) · 숨기기/보이기 · 레이어 › · 노드 전부 펼치기/접기. 오브젝트끼리 부모·자식은 없다 — 모두 그 무대·층의 Content에 선다.

씬은 저작본에 남고 `motions.json`에는 들어가지 않는다. 모션의 주인은 **rigKind**다 — 고른 오브젝트의 리그가 다르면 모션 목록에서 "안 맞음"으로 흐려진다.

## 9-1. 이모지 — 그림 여럿 + 자기 타임라인

이모지는 그림 여러 장이 한 타임라인(24fps)을 함께 쓴다. 이름 붙은 **구간**(프레임, 끝 포함)을 등장 · 머묾 · 퇴장에 **이으면** 런타임이 등장 → 머묾 되풀이 → (내리면) 퇴장으로 돌린다. 머묾을 잇지 않으면 타임라인 전체가 한 번 돌고 사라진다.

만들어 둔 것을 먼저 보려면 **열기…**로 `examples/emoji/emoji-examples.motion-authoring.json`을 연다(런타임의 견본 셋 `star` · `question` · `twinkle`).

**화면의 말.** 화면은 만드는 사람의 말을 쓰고, 파일과 런타임 문서는 제 이름을 쓴다. 노드 이름은 줄에 마우스를 올리면 나온다.

| 화면 | 파일 · 런타임 문서 |
|---|---|
| 그림 | 리그(`rigs[]`) — 그림 하나에 리그 하나. 줄의 `body`는 `body/EmojiRig_Image` |
| 이모지 전체 | `Emoji_Offset`(`rig: ""`) |
| 머리에서 X · Y | 오프셋(`offset`) — 로케이터(머리의 자리)에서 잰 자리 |
| 자리 · 크기 · 회전 · 투명도 · 그림 | 채널 `x` `y` · `scaleX` `scaleY` · `rotation` · `alpha` · `sprite` |
| 크기(그림의 칸) | 기본 배율(`rigs[].scale`) |
| 인물의 방향을 따르지 않기 | `fixedSide` |
| 인물이 돌아서도 이 그림은 뒤집지 않기 | `upright` |
| 게임처럼 재생 | 수명(등장 → 머묾 × 바퀴 → 퇴장)을 런타임과 같은 계산으로 돌린다 |

해 보기:

1. 툴바의 **이모지**로 이모지 모드에 들어간다. 왼쪽 **이모지 추가**가 **새 이모지**의 첫 화면을 연다.
2. 첫 화면에서 셋을 정한다 — **그림**(PNG를 창에 끌어다 놓거나 "그림 고르기…". 한 장이 그림 하나가 된다) · **어떻게 뜨는가**(한 번 재생하고 사라진다 / 머문다) · **움직임**(등장 · 머묾 · 퇴장, 없음도 된다). 아래 한 줄이 무엇이 만들어지는지 적는다. **만들기**를 누르면 움직이는 이모지가 생긴다(되돌리기 한 칸).
3. 뷰포트에 인물의 머리에 선 이모지가 보인다. **▶**(또는 Alt+Q)로 재생해 보고, 띠 윗줄의 **게임처럼 재생**으로 등장 → 머묾 × 바퀴 → 퇴장을 본다.
4. 고친다 — 뷰포트에서 그림을 눌러 **끌어** 자리 · 크기 · 회전을 잡고(Auto Key를 켜면 키), 띠의 끝을 끌어 등장 · 머묾 · 퇴장의 길이를 맞추고, 그래프에서 곡선을 다듬는다. 다른 움직임을 얹으려면 그림을 고르고 **움직임 가져오기 ▾**.
5. 이모지 전체의 자리(머리에서 얼마나 떨어져 뜨는가)는 왼쪽 목록에서 그 이모지를 누르고 뷰포트에서 끈다(또는 오른쪽의 **머리에서 X · Y**).
6. 툴바의 **emojis.json 내보내기…**로 내보낸다. 막는 문제가 있으면 문제 칸에 `이모지 …`로 나오고 쓰지 않는다.

손으로 처음부터 지으려면 첫 화면의 **빈 이모지로 시작** — 빈 그림 `body` 하나가 생긴다. 왼쪽 그림 목록에서 `body`를 고르고 오른쪽의 **그림 더하기…**로 PNG를 넣는다(문서 기준 경로로 적힌다). 여러 장이면 **그림 넘기기**(시작 · 몇 프레임마다 · 몇 번)가 계단 키를 한 번에 깐다. 키는 오른쪽 아래 **키 놓기**의 단추(자리 · 크기 · 회전 · 투명도 · 그림)나 그래프 목록 "키 없음" 줄의 **＋**로 놓는다. 그래프 툴바의 **step**은 계단 키다.

**새 이모지의 첫 화면.**

| 칸 | 뜻 |
|---|---|
| 이름 | 영문 소문자 · 숫자 · `_`. 대본의 `<<emoji 누구 이름>>`이 부르는 이름이다 |
| 1. 그림 | PNG를 끌어다 놓거나 고른다(여러 장). 한 장이 그림 하나 — 그림의 이름은 파일 이름에서 온다. 순서가 그려지는 순서다(아래가 위) — 목록에서 고르고 **▲ ▼**로 바꾼다. 비워 두면 빈 그림 `body` 하나 |
| 2. 어떻게 뜨는가 | **한 번 재생하고 사라진다**(구간 없이 타임라인 전체) / **머문다**(머묾 구간을 되풀이 — `<<emoji_off>>`로 내린다) |
| 3. 움직임 | 등장 · 머묾 · 퇴장의 움직임(아래 "움직임 가져오기"의 여섯) 또는 없음. 이모지 전체에 키로 들어간다 — 그림이 여럿이어도 함께 움직인다 |
| 만들기 | 이모지 · 그림 · 구간 · 키를 한 칸에 짓고 그 이모지를 고른다 |
| 빈 이모지로 시작 | 그림도 움직임도 없이 빈 그림 `body` 하나 |

길이는 1초(24프레임)로 시작한다 — 오른쪽의 **길이(프레임)**로 바꾸고 띠를 끌어 맞춘다.

**수명의 띠.** 뷰포트와 타임 슬라이더 사이의 두 줄이다.

| | |
|---|---|
| 윗줄의 글 | 이 이모지가 어떻게 사는가 — "머무는 이모지 — 등장 한 번 → 머묾 되풀이 → 내리면(emoji_off) 퇴장" / "한 번 재생하고 사라진다" |
| **+ 등장 · + 머묾 · + 퇴장** | 아직 없는 자리에 구간을 놓고 잇는다(한 칸). 이웃 사이의 빈 곳을 채운다 |
| 색 띠 | 등장(초록) · 머묾(노랑) · 퇴장(파랑). 점선은 어디에도 잇지 않은 구간 |
| 띠의 끝 끌기 / 몸통 끌기 | 시작 · 끝을 / 통째로 옮긴다. 프레임에 붙는다. 놓을 때 되돌리기 한 칸 |
| 띠에서 오른쪽 단추 | "…에서 풀기(구간은 남는다)" · "구간 지우기" |
| **게임처럼 재생** · 머묾 n 바퀴 | 수명을 런타임과 같은 계산으로 돌린다. 머묾을 몇 바퀴 돈 뒤 내릴지 |

**움직임 가져오기.** 띠 윗줄의 **움직임 가져오기 ▾**가 미리 만든 움직임의 키를 넣는다 — 빈 타임라인에서 시작하지 않아도 된다.

| 자리 | 움직임 |
|---|---|
| 등장 | **튀어나오기**(크기 0 → 조금 크게 → 제 크기, 투명도 0 → 1) · **서서히 나타나기**(투명도 0 → 1, 조금 아래에서 제자리로) |
| 머묾 | **두근거리기**(크기가 조금 커졌다 돌아온다) · **흔들기**(좌우로 기울었다 돌아온다) |
| 퇴장 | **위로 사라지기**(위로 올라가며 사라진다) · **줄어들며 사라지기**(크기 1 → 0) |

- **대상**은 고른 그림들이다(여럿이면 전부). 그림을 고르지 않았으면 이모지 전체.
- **넣을 곳**은 띠에서 고른 구간이다. 고른 구간이 없으면 그 움직임의 자리(등장 · 머묾 · 퇴장)의 구간이고, 그 자리가 비었으면 구간도 함께 놓인다. 메뉴의 줄마다 어디에 넣는지 적혀 있다.
- 되돌리기 한 칸이다. 넣은 것은 **그냥 키**다 — 그래프와 뷰포트에서 마음대로 고친다. 그 범위의 같은 성분의 키만 바뀐다.

이름과 프레임을 숫자로 적으려면 오른쪽의 **구간과 잇기**를 쓴다(이모지를 골랐을 때 — 띠를 누르면 그 구간이 거기서도 골라진다). 구간을 더 두거나(잇지 않은 구간) 한 구간을 두 자리에 잇는 것도 거기서 한다.

**인물과 머리의 자리.** 이모지는 인물의 **머리**에 서서 보인다 — 십자가 머리의 자리이고 "머리에서 X · Y"가 거기서 잰다. 인물은 초상(캐릭터 모션 모드의 씬 탭 "초상 PNG…")이 있으면 초상, 없으면 실루엣이다. 뷰포트 오른쪽 위 도구 띠의 오른쪽이 보기의 단추다.

| 단추 | 뜻 |
|---|---|
| **인물** | 인물(초상 · 실루엣)을 보이거나 감춘다. 감춰도 이모지의 자리는 그대로다 |
| **◀ 왼쪽 보기** | 왼쪽을 보는(뒤집힌) 인물에게 뜨는 모습 — 인물과 이모지가 거울에 비친다. 보기만 바뀐다. 켠 동안 그림을 끌어도 기본 자리가 바뀌지 않는다(끄고 옮긴다) |
| **맞춤 F** | 그림들이 뷰포트 가운데를 채우게 보기를 옮긴다 |
| **인물과 함께** | 이모지와 인물의 머리가 같이 보이게 보기를 옮긴다(이모지를 고르면 처음에 이렇게 보인다) |

머리의 자리는 캐릭터마다 다르고 **런타임의 표**가 든다. 리그 덤프 옆에 `presets/emoji-locator.json`(런타임의 덤프)이 있으면 툴이 그 캐릭터(씬 탭의 배역 키)의 자리를 읽어 보이고, 없으면 발에서 800px 위에 보인다. 이것은 **보기**다 — 이모지의 값도 내보내는 파일도 바뀌지 않는다.

**뷰포트에서 직접 만진다.** 뷰포트 오른쪽 위의 띠(또는 **Q · W · E · R**)가 도구다 — 선택 · 이동 · 회전 · 크기. 그림을 눌러 고르고 매니퓰레이터(화살표 · 고리 · 상자)를 끈다. 이동 도구는 그림을 눌러 그대로 끌어도 된다.

| | Auto Key 꺼짐 | Auto Key 켜짐 |
|---|---|---|
| 그림을 끌면 | **기본값**이 바뀐다 — 자리 · 크기 · 회전(키가 아니다. 크기는 값 하나라 가로 세로가 같이 간다) | **지금 프레임에 키**가 놓인다 — 자리 · 회전 · 크기(축마다 따로) |
| 이모지 전체를 끌면(왼쪽 목록에서 이모지를 눌렀을 때) | 머리에서의 자리가 바뀐다. 회전 · 크기는 기본값이 없어 끌 수 없다 | 이모지 전체의 키가 놓인다 |

- 끄는 동안은 보이기만 하고, 놓을 때 되돌리기 한 칸이다. **S**는 끌지 않고 지금 값을 키한다(도구의 종류만 — 선택 도구면 자리 · 회전 · 크기 셋 다).
- 뷰포트 왼쪽 아래의 글이 지금 무엇을 끌면 무엇이 바뀌는지 적는다("이동(W) · body: 끌면 9프레임에 키").
- 키를 놓거나 값을 바꾼 뒤에도 **보고 있던 프레임에 그대로 있다**(처음 프레임으로 돌아가지 않는다).
- **여럿 고르기** — **Shift**(또는 Ctrl)로 누르면 더하거나 뺀다. 빈 데서 끌면 **상자**가 생기고 닿은 그림들이 골라진다. 왼쪽 그림 목록에서 Shift · Ctrl로 골라도 같다. 여럿을 고르면 함께 끌리고 **S**가 전부를 키한다 — 여럿이어도 되돌리기 한 칸이다. 매니퓰레이터는 고른 그림들의 **가운데 점**에 선다(축의 방향은 마지막에 고른 그림의 것).
- **무리째 돌리기 · 늘이기** — 여럿을 고르고 **회전(E)**하면 그 가운데 점을 축으로 무리 전체가 돈다: 그림마다 각이 돌고 자리도 그 점을 돌아 옮겨 간다(별 셋이 원을 그리며 돈다). **크기(R)**도 같다 — 그림이 커지면서 가운데 점에서 그만큼 멀어진다(축 손잡이는 그 축의 방향으로만 벌린다). Auto Key가 켜져 있으면 회전 · 크기의 키와 함께 **자리의 키**도 놓인다. 하나만 고르면 전처럼 제 가운데에서 돌고 커진다. 여럿을 고른 채 그 가운데 하나를 끌지 않고 누르면 그것만 남는다. 오른쪽은 값의 칸을 내지 않는다(값은 하나만 골라 고친다).
- **고르기** — 그림의 빈 곳(투명한 데)은 눌러도 맞지 않는다: 사각형이 겹쳐도 보이는 그림을 누른 것이 골라진다. 그림이 겹친 자리에서는 이미 고른 그림을 지키고(그래서 덮인 그림도 끌 수 있다), 끌지 않고 다시 누르면 그 밑의 것으로 넘어간다. 아무 그림도 없는 데를 누르면 **선택이 전부 풀린다** — 고른 것이 없으면 매니퓰레이터도 없고 끌어도 아무것도 옮겨지지 않는다. **이모지 전체**(머리에서의 자리 · 이모지 전체의 키)를 끌려면 왼쪽 목록에서 그 이모지를 누른다(이모지를 처음 고르면 이 상태다).

**키 놓기.** 오른쪽 아래의 단추 다섯 — **자리 · 크기 · 회전 · 투명도 · 그림**. 누르면 그 종류의 지금 값이 지금 프레임에 키로 놓인다(채널이 없으면 생긴다). 대상은 단추 위에 적힌 대로 **고른 그림들**이고(여럿이면 전부에, 한 칸), 고르지 않았으면 이모지 전체다. 투명도와 그림 바꾸기는 뷰포트에서 끌 수 없는 값이라 이 단추로 키를 놓고 그래프에서 값을 바꾼다. **그림**은 그림 파일이 있는 그림을 골랐을 때만 켜진다. **계단**은 그래프에서 고른 키를 계단으로 바꾼다.

**종류별 칸.** 그래프 툴바의 **종류별 칸**(기본 켜짐)이 곡선을 종류마다 한 칸씩 나눠 그린다 — 자리(px) · 크기(배율) · 회전(도) · 투명도(0…1)는 값의 크기가 달라서 한 눈금에 그리면 작은 것이 바닥에 깔리기 때문이다. 칸마다 세로 눈금이 따로이고 놓인 키에 저절로 맞는다(끄는 동안은 그대로, 놓으면 다시 맞는다). 가로(시간)는 전부 같다. 키를 끌면 그 칸의 눈금으로 움직인다. 리전(상자로 늘이기)은 한 칸의 키만 묶는다. 끄면 전처럼 한 눈금에 전부 그리고 세로로 옮기고 확대할 수 있다.

**트윈머신.** 툴바의 **트윈머신**이 작은 창을 띄운다 — 마야의 tweenMachine처럼 **앞 키와 뒤 키 사이의 값**을 슬라이더로 골라 지금 프레임에 키로 놓는다(사이 포즈 · 브레이크다운). 창은 본 창 위에 떠 있고, 띄운 채 뷰포트 · 타임라인 · 그래프를 그대로 만진다.

1. 그림을 고르고(안 고르면 이모지 전체) 두 키 **사이의 프레임**으로 간다. 창의 첫 줄이 무엇에, 어느 키와 어느 키 사이에 놓이는지 적는다.
2. **슬라이더**를 끈다 — 0%는 앞 키의 값, 100%는 뒤 키의 값. 끄는 동안 뷰포트와 그래프가 따라오고, 놓으면 되돌리기 한 칸이다. **단추**(0 · 25 · 33 · 50 · 67 · 75 · 100)는 누르면 바로 놓인다.
3. **오버슈트**를 켜면 −50 ~ 150%까지 간다 — 100% 위는 뒤 키를 지나치는 것, 0% 아래는 반대쪽으로 먼저 가는 예비 동작.

**캐릭터 모션**에서도 같은 창을 쓴다 — 마야처럼 **고른 컨트롤러**(뷰포트 · 하이어아키 · 아웃라이너에서 고른 몸 · 숙임 …)의 곡선에 놓인다. 포즈 전체에 놓으려면 창의 **"고른 컨트롤러만이 아니라 모션 전체에"**를 켠다. 그래프 목록에서 곡선을 골랐으면 그것만. 트윈은 키를 바로 놓는다: 그 프레임에 키 없는 포즈(주황)를 들고 있었으면 버리고 키가 그 자리를 차지한다(되돌리면 포즈도 돌아온다). 클립을 보는 중에는 쓰지 않는다.

비율은 값의 비율이다(시간이 아니다). 자리 · 크기 · 회전 · 투명도 가운데 그 프레임의 앞과 뒤에 키가 있는 곡선에만 놓인다. 그래프 목록에서 곡선을 골랐으면 그것만 건드린다. 그 프레임에 이미 키가 있으면 값만 바뀐다. 창의 자리와 열려 있었는지는 다음에 열 때 그대로다.

**고른 것이 그래프를 정한다.** 그림을 고르면 그래프 왼쪽의 목록과 곡선이 **그 그림의 것만** 보인다(여럿을 고르면 그것들). 그림을 고르지 않았으면 전부 — 이모지 전체와 모든 그림 — 가 보인다.

**고른 것이 오른쪽을 정한다.** 이모지를 고르면 오른쪽은 이모지의 값(이름 · 머리에서의 자리 · 길이 · 방향 · 구간과 잇기), 왼쪽에서 그림을 고르면 그 그림의 값(이름 · 그림 파일 · 자리 · 크기 · 회전 · 뒤집지 않기 · 그림 넘기기)이다. 이모지를 고른다고 그림이 저절로 골라지지 않는다. 키 놓기의 단추는 두 경우 모두 아래에 있고, 대상은 고른 그림을 따라온다(안 골랐으면 이모지 전체).

| 조작 | 뜻 |
|---|---|
| 뷰포트에서 그림 끌기 | Auto Key가 꺼져 있으면 그 그림의 **기본값**(오른쪽의 자리 · 크기 · 회전 칸과 같다), 켜져 있으면 지금 프레임의 키 — 위의 표 |
| 머리에서 X · Y | 이모지 전체의 자리(머리 기준점에서). 키는 "이모지 전체" 줄에 놓는다 |
| 투명도 · 그림 | 이모지의 타임라인에만 쓰는 종류 — 불투명도, 그림 바꾸기(몇 번째 그림, 늘 계단) |
| 인물의 방향을 따르지 않기 | 이모지의 칸. 인물이 뒤집혀도 만든 쪽 그대로 선다 — 머리 위 한가운데에 뜨는 것 · 화면 기준으로 흐르는 것 |
| 인물이 돌아서도 이 그림은 뒤집지 않기 | 그림의 칸. 물음표 · 느낌표 · 글자처럼 거울에 비치면 안 되는 그림 — 이모지가 거울에 비쳐도 그림과 그 키는 만든 그대로, 기본 자리만 거울 쪽으로 간다. 방향을 따르지 않는 이모지에서는 흐려진다(뜻이 없다) |

그림의 기본 자리(`EmojiRig_Place`)는 키를 받지 않는다 — 키는 이모지 전체(`Emoji_Offset`)와 그림마다의 노드(`그림 이름/EmojiRig_Image`)에만 놓인다. 미리보기는 내보낸 정의를 코어로 돌린 것이라 게임과 같다.

**좌우** — 이모지는 오른쪽을 보는 인물을 기준으로 만든다(자리 · x 키 · 회전을 그 기준으로). 인물이 왼쪽을 보면 런타임이 이모지를 통째로 거울에 비추니 따로 만들지 않는다.
"뒤집지 않기"를 켠 그림이 바깥으로 흐르는 x 키를 가졌다면 뒤집힌 인물에게는 안쪽으로 흐른다 — 키가 만든 그대로 보이기 때문이고 버그가 아니다. 그런 움직임은 이모지 전체의 키로 잡는다(그것은 뒤집힌다). 도구 띠의 "◀ 왼쪽 보기"를 켜고 확인한다.

## 10. 내보내기와 문제 칸

- **내보내기 범위**(왼쪽 콤보): 전체 / 이 rigKind만 / 이 오브젝트가 입는 모션만. 고른 범위의 문제만 내보내기를 막는다.
- 빨강 **⚠**는 규칙 위반(내보내기 불가), 노랑 **△**는 경고(내보내기 가능). 각 줄의 **돕는 손** 버튼이 한 번에 고친다(되돌리기 한 번):
  끝 키를 길이로 옮기기 · 길이를 마지막 키에 맞추기 · 길이 자리에 키 넣기 · 마지막 키를 중립값으로 · 첫 키를 0초로 · 끝을 commit으로 · 이름 고치기.
- 규칙(코어 `MotionRules`): 이름은 소문자·숫자·`_`, 성분마다 키 둘 이상, 첫 키는 0초, 마지막 키는 길이, 시각 오름차순, 가중 탄젠트 없음. 툴 쪽 규칙: 캐릭터 모션에는 계단 키 · `alpha` · `image` 채널을 쓰지 않는다(이모지의 타임라인에만).
- 키가 있는 성분은 전부 나간다(상수 중립값도). 채널에 mode는 없다 — 뜻은 대본 커맨드가 정한다.

## 11. 설정 창

툴바 **설정…**: 리그 노드 보기 · 무대 뼈대 보기 · 시간 스냅 간격(1/24 기본 · 1/60 · 1/120) · 새 키 탄젠트 · 시간 표시(프레임/초) · 자동 저장 간격. 바꾸는 즉시 적용, 닫을 때 저장.
시간 스냅 켬/끔과 값 스냅은 그래프 툴바에, Auto Key는 하단 줄에 있다.

## 12. 자주 묻는 것

| 증상 | 이유 · 할 일 |
|---|---|
| 내보내기 버튼이 안 먹는다 | 문제 칸에 ⚠가 있다. 돕는 손을 누르거나 키를 고친다 |

| 자동 저장본이 보인다 | `<이름>.autosave.motion-authoring.json`은 5분마다(바뀐 것이 있을 때만). 저장 상태는 건드리지 않는다 |
