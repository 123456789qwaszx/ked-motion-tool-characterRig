# 실제로 쓸 세트 — 연출 카드의 몸짓 · 감정 아이콘

예시(`examples/`)가 툴의 쓰는 법을 보이는 것이라면, 이 폴더는 **대본에서 실제로 부를 것**을 모아 둔 자리다.
`ked-vn-workspace`의 연출 참고집(원본 게임에서 잰 연출)에 든 **몸짓 카드 16장(G01~G16)**과 **감정 아이콘 카드 22장(I01~I22)**을
이 툴에서 고칠 수 있는 꼴로 옮겼다. 둘을 **저작본 하나**에 함께 둔다 — 파일 하나를 열고 툴바의 "캐릭터 모션" · "이모지"를 오가며 본다. (2026-11-22 다시 지음)

| 파일 | 무엇 |
|---|---|
| `cards.motion-authoring.json` | 몸짓 17개(G01~G16 + G12의 좌우 반대) · 몸짓을 차례로 늘어놓은 클립 `review`(훑어보기용 — 내보내지 않는다) · 감정 아이콘 22개 |
| `export/motions.json` · `export/emojis.json` | 위에서 내보낸 것(`motions/2` · `emojis/2`). 런타임에 들일 때 이것을 쓴다 — 런타임의 형식이 둘이라 산출물은 둘이다 |
| `from-catalog.py` | 저작본을 참고집에서 다시 짓는다(아래 "참고집에서 다시 짓기") |
| `fetch-art.py` | `art/`를 채운다 — 원본 그림을 `ked-originals`에서 복사 |
| `art/` | **git 밖**(`.gitignore`). 원본 이모지 그림 36장(`o_<이름>.png`)과 미리보기의 초상 하나 |

## 처음 한 번 — 그림 채우기

```
python library/fetch-art.py                     # 저장소 옆의 옆 ../../ked-originals 를 본다
python library/fetch-art.py D:\어딘가\ked-originals
```

그림이 없어도 검증 · 내보내기는 된다(그림이 없다는 알림만 나온다). 툴에서는 자리표시로 보인다.
게임은 그림을 **파일 이름**으로 찾는다 — `art/o_star_1.png`가 스프라이트 `o_star_1`(`Resources/Emojis/o_star_1`)이 된다.

## 고친 뒤

툴에서 열어 고치고 저장한 뒤 `export/`에 다시 내보낸다(테스트 `LibraryTests`가 저작본과 `export/`가 같은지 본다).

```
./mt export library/cards.motion-authoring.json library/export/motions.json
./mt emojis library/cards.motion-authoring.json library/export/emojis.json
```

반대쪽(`flip`)은 따로 만들지 않는다 — 툴의 "⇄ 반대쪽 보기"로 반대쪽에 뜬 모습을 본다(`./mt pose … --emoji <이름> --side flip`도 같다).

## 참고집에서 다시 짓기

참고집의 카드가 바뀌면(몸짓 클립을 다시 재거나 감정 아이콘을 다시 지으면) 저작본을 다시 짓는다. **통째로 다시 쓰므로 툴에서 고친 것은 덮인다** — `git diff`로 보고 고른다.

```
python library/from-catalog.py                                    # 저장소 옆 ../ked-vn-workspace 를 본다
python library/from-catalog.py D:\어딘가\ked-vn-workspace --report   # 아래 표(키 수 · 잰 곡선과의 차)도 낸다
```

읽는 것은 `catalog/clips.json`(몸짓 카드의 프리셋 클립)과 `runtime/Assets/Workspace/Dialogue/ch05_emojis.json`(감정 아이콘의 정의)이다. 다시 지은 뒤 위의 "고친 뒤"대로 `export/`를 다시 낸다.

## 몸짓

다시 지은 법: 참고집의 클립은 원본의 실제 한 건을 1/30초마다 잰 곡선이라 키가 프레임마다 박혀 있다 — 그대로는 툴에서 고치기 어렵다.
그 곡선에서 **2px 넘게 달라지지 않는 동안 키를 하나씩 덜어 냈다**(꼭짓점의 키는 남긴다). 남은 키는 고치기 쉬운 종류로 바꿨다 — 양 끝과 꼭짓점은 `flat`, 그 밖은 `auto`. 그래도 2px을 넘는 자리만 잰 기울기 그대로(`free`)다.
아래 "차"는 잰 곡선과 다시 지은 곡선의 차이다(툴이 내보낸 `motions.json`을 견줬다). 잰 곡선이 거친 것(통통 · 크게 들썩 · 빠른 통통)은 키가 많이 남는다.

## 감정 아이콘

모두 **한 번 뜨고 사라지는** 꼴이다(구간 없음 — 대본의 `<<emoji 누구 이름>>`). 그림은 뒤집지 않는다(`upright`).
작업공간의 정의(`ch05_emojis.json` — 원본에서 잰 움직임 `catalog/emoji-motion.json`으로 지은 것)를 **그대로 옮겼다**: 자리 · 크기 · 키의 값과 기울기가 같다(프레임 → 초, 프레임당 기울기 → 초당).
이 저작본에서 내보낸 `emojis.json`을 그 정의와 1/4프레임마다 견주어 모든 값이 같다. 키는 조금 많다 — 내보내기가 구간의 끝에 세우는 키, 그리고 아래의 계단.

|---|---|---|---|---|

- 길이는 재생되는 시간(프레임 수 ÷ 30)이다. 툴의 타임라인은 0 ~ (프레임 수 − 1)/30초다.
- **계단을 옮긴 자리** — 정의의 계단 키는 들어오는 기울기를 가질 수 있지만 저작본의 `step`은 들어오는 쪽이 평평하다. 그런 키는 "그 기울기로 들어오는 `free` 키 + 한 프레임 뒤 같은 값의 `step` 키"로 옮겼다(`sleepy`의 Z가 사라지는 자리). 재생되는 값은 같다.
- 녹화로는 아직 확인하지 않았다 — 정의가 원본과 맞는지는 작업공간에서 녹화로 본다.
- **반대쪽** — 원본은 이모지를 인물의 등 쪽에도 띄운다. 런타임은 대본이 쪽을 고른다 — `<<emoji 누구 이름 flip>>`이 정의의 반대쪽에 띄운다(오프셋 · 그림의 자리 · 이모지 전체의 움직임이 거울에 비치고, 그림은 모두 `upright`라 바로 선다). 그래서 좌우 사본을 두지 않는다.
