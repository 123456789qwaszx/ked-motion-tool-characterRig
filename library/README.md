# 실제로 쓸 세트 — 캐릭터 모션 · 이모지

예시(`examples/`)가 툴의 쓰는 법을 보이는 것이라면, 이 폴더는 **대본에서 실제로 부를 것**을 모아 둔 자리다.
원본 게임 5장에서 잰 연출(`ked-vn-workspace`의 연출 참고집)을 이 툴에서 고칠 수 있는 꼴로 옮겼다. (2026-11-18)

| 파일 | 무엇 |
|---|---|
| `motions.motion-authoring.json` | 캐릭터 모션 13개 — 참고집 몸짓 카드 G01~G12(+ G12의 좌우 반대). 툴에서 훑어보는 클립 `review`(내보내지 않는다) |
| `emojis.motion-authoring.json` | 이모지 22종. 반대쪽에 띄울 때는 대본이 고른다 — `<<emoji 누구 이름 flip>>`(아래 "반대쪽") |
| `export/motions.json` · `export/emojis.json` | 위 둘에서 내보낸 것(`motions/2` · `emojis/2`). 런타임에 들일 때 이것을 쓴다 |
| `fetch-art.py` | `art/`를 채운다 — 원본 그림을 `ked-originals`에서 복사 |
| `art/` | **git 밖**(`.gitignore`). 원본 이모지 그림 36장(`o_<이름>.png`)과 미리보기의 초상 하나 |

## 처음 한 번 — 그림 채우기

```
python library/fetch-art.py                     # 저장소 옆의 옆 ../../ked-originals 를 본다
python library/fetch-art.py D:\어딘가\ked-originals
```

그림이 없어도 검증 · 내보내기는 된다(그림이 없다는 알림만 나온다). 툴에서는 자리표시로 보인다.
게임은 그림을 **파일 이름**으로 찾는다 — `art/o_star_1.png`가 스프라이트 `o_star_1`(`Resources/Emojis/o_star_1`)이 된다.

## 고친 뒤

툴에서 열어 고치고 저장한 뒤 `export/`에 다시 내보낸다(테스트 `LibraryTests`가 저작본과 `export/`가 같은지 본다).

```
./mt export library/motions.motion-authoring.json library/export/motions.json
./mt emojis library/emojis.motion-authoring.json library/export/emojis.json
```

반대쪽(`flip`)은 따로 만들지 않는다 — 툴의 "⇄ 반대쪽 보기"로 반대쪽에 뜬 모습을 본다(`./mt pose … --emoji <이름> --side flip`도 같다).

## 캐릭터 모션

- **5장의 19종**은 작업공간의 정의(`ch05_emojis.json`)와 같은 값이다 — 11-18에 30fps로 옮기기 전에는 여기서 내보낸 것이 그 파일과 키 하나까지 같았다(지금은 프레임 n → round(n × 1.25)로 옮겨 프레임 숫자가 다르고, 시각은 1/60초 안에서 같다). 길이는 다시 잰 표시 시간(`emoji-times.json`의 중앙값)과 맞는다. 자리는 잰 값이고, 움직임 · 배율은 영상을 보고 맞춘 것이라 **녹화로 확인하지 않았다**.
- **새 3종**(`angry` · `sleepy` · `think`)은 5장에 쓰이지 않은 그림이다. 자리 · 길이 · 움직임은 비슷한 종류에서 가져와 지었다 — 잰 값이 아니다.
- **반대쪽** — 원본은 이모지를 인물의 등 쪽에도 띄운다(5장 215번 중 51번, 인물 방향을 되돌려 잰 것). 런타임은 대본이 쪽을 고른다 — `<<emoji 누구 이름 flip>>`이 정의의 반대쪽에 띄운다(오프셋 · 그림의 자리 · 이모지 전체의 움직임이 거울에 비치고, 그림은 모두 `upright`라 바로 선다). 그래서 좌우 사본(`<종류>_l`)을 두지 않는다(11-18에 걷었다).
  - 사본과 다른 점 하나 — `flip`은 그림의 배치도 거울에 비춘다(사본은 배치를 그대로 두었다). 배치가 좌우 대칭이 아닌 `symbol`(`!`와 `?`의 자리가 바뀐다) · `think`(생각 꼬리가 머리 쪽으로) · `flower` · `star` · `flurry`가 사본과 다르게 보인다.
